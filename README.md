# Lyra Nightshade — Second Life Site

A multi-page personal site showcasing a Second Life profile: avatars, categories, gallery, and contact info.

## Pages

- `index.html` — Home / hero
- `about.html` — About me + timeline
- `avatars.html` — Avatar showcase
- `categories.html` — Category overview (fashion, builds, roleplay, etc.)
- `gallery.html` — Filterable photo gallery
- `contact.html` — Contact links + message form

## Customizing

- Replace the placeholder text (name, bio, links) directly in the HTML files.
- Drop your own screenshots into `images/` using these filenames, or update the `src` attributes to match your own filenames:
  - `placeholder-portrait.jpg`
  - `avatar1.jpg` – `avatar4.jpg`
  - `gallery1.jpg` – `gallery6.jpg`
- If an image is missing, a placeholder graphic is shown automatically so the layout never breaks.

## Running locally

Just open `index.html` in a browser — no build step required.

## Deployment

This site is static and deployed via GitHub Pages from this repository.
